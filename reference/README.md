# Reference material

Background reading that comes with the course. None of it is required: the
slides, the exercises and the demos stand on their own. This is here for when
you want to go further on a topic, or want something to read offline.

## `python-docs/`

The official Python 3.14 documentation, as PDFs, from `docs.python.org`.

- **`tutorial.pdf`** : the official tutorial. The closest thing to a second
  opinion on everything this course covers.
- **`library.pdf`** : the standard library reference, and the one you will open
  most often. Every module the course mentions is described here in full.
- **`reference.pdf`** : the language reference, for when you need to know
  exactly what a piece of syntax means.
- **`using.pdf`** : installing and running Python on each platform.
- **`faq.pdf`** and **`whatsnew.pdf`**.
- **`howto-*.pdf`** : short guides on regular expressions, sorting, Unicode,
  functional programming, enums, annotations, logging, argparse, descriptors
  and the method resolution order.

The same documentation is online at `https://docs.python.org/3/`, which is
always the most current version.

## `articles/`

Individual articles on single topics, collected over the years: decorators,
generators, garbage collection, the GIL, XML parsing, database access, CSV
files, f-strings, `with`, subprocesses, sockets and more. Quality and age vary,
so treat them as a starting point rather than as authority; where one disagrees
with the official documentation, the documentation wins.

## `books/`

Full-length books, for reading rather than reference.

## `cheatsheets/`

One-page summaries to keep beside you while you work.

## `gui/`

Graphical user interface material. **This is not part of PRG400**, which is a
language fundamentals course, but Python GUI work is a common next question.

- `tkinter/` and `tkinter-extra/` : the toolkit that ships with Python
- `qt-examples/` : the PySide and PyQt bindings, by example
- `examples/` and the two PDFs : a survey of the options

## `jupyter/`

Notebook material. Jupyter runs Python cell by cell in the browser and is
common in data science work.

## `packaging/`

Turning a project into something installable, and publishing it.

## `perl-to-python/`

A short mapping of Perl idioms onto Python ones, for those arriving from Perl.
The course itself is written to assume no particular background.
